Privacy, with a
lighter footprint.

This policy explains what happens to images and information when you use SYXLOR BG Remover.

Images you process

When you submit an image, this application sends it to the server running SYXLOR BG Remover so it can be decoded and prepared for processing. The server sends the image to the AI provider configured for this deployment to generate a foreground segmentation, then applies it to the original image pixels.

The application does not save submitted or processed images to a database or image library. Image data is handled in memory while a request is processed. Your browser keeps preview copies in the current page session so you can review and download them; those copies are released when you clear the queue or close the page.

The configured AI provider processes the image under its own API terms and privacy policy. Do not submit confidential, sensitive, or regulated content unless your organization has approved that use. Review the selected provider's privacy information for details about its handling.

Information and diagnostics

The server may record operational request information and errors in its standard logs, such as timestamps, route names, and failure details. Configure log retention and access on the server where you deploy this application. Do not enable request-body or image-content logging.

This application does not require an account and does not use advertising trackers. The hosting environment may keep ordinary network logs according to its own configuration.

Where processing happens

Image processing occurs on the application server you choose and through the configured provider's hosted API. The server operator controls hosting, access, and operational log retention. A deployment may be reachable by other people unless the operator protects it with network or platform access controls.

Your choices

You choose whether to upload an image. You can remove queued previews at any time. Avoid uploading content you do not have permission to process, and use deployment-level access controls for private installations.

Changes and contact

This policy may be updated as the application changes. The date above shows when it was last revised. For questions, contact the operator who provided access to this deployment.
